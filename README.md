# StudyTrack – Student Task Management System

StudyTrack is a beginner-friendly **MERN Stack Student Task Management System** developed as a college project. It helps students manage tasks, track progress, and allows administrators to manage users and assignments.

## 🚀 Features

* 🔐 Clerk Authentication
* 👨‍🎓 Student & Admin roles
* 📝 Create, update and delete tasks
* 📊 Task progress tracking
* 🔍 Search and filter tasks
* 👥 User management
* 📱 Responsive UI
* 🔒 Role-Based Access Control (RBAC)

## 🛠️ Tech Stack

**Frontend:** React.js, Vite, CSS
**Backend:** Node.js, Express.js
**Database:** MongoDB, Mongoose
**Authentication:** Clerk
**Tools:** Git, GitHub, VS Code

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/yourusername/studytrack.git
cd studytrack
```

### 2. Install Dependencies

```bash
npm install
cd server && npm install
cd ../client && npm install
```

### 3. Configure Environment Variables

Create `.env` files in the `server` and `client` folders and add your MongoDB and Clerk credentials.

### 4. Run the Project

Backend:

```bash
cd server
npm run dev
```

Frontend:

```bash
cd client
npm run dev
```

Open:

```text
http://localhost:5173
```
